🧮 Módulo math: Tu Calculadora Científica

¿Qué es? Imagina que tu código necesita hacer cálculos complejos (raíces, redondear). El `+` y el `*` se quedan cortos. Aquí entra math, tu calculadora virtual.

Función ¿Para qué sirve? (En español simple) Ejemplo
math.sqrt(x) Calcula la Raíz Cuadrada de un número. math.sqrt(25) da 5.0
math.ceil(x) Redondea hacia ARRIBA al entero más cercano (Techo). math.ceil(4.1) da 5
math.floor(x) Redondea hacia ABAJO al entero más cercano (Piso). math.floor(4.9) da 4

Paso a Paso: El problema de los buses

Supongamos que vas de paseo con 41 alumnos. En cada bus caben exactamente 40 alumnos. ¿Cuántos buses necesitas?

📄 buses.py 
import math

alumnos = 41
capacidad_bus = 40

# Si dividimos 41 / 40 nos da 1.025 buses
division = alumnos / capacidad_bus

# Pero no podemos arrendar "0.025 buses". Necesitamos redondear hacia ARRIBA.
buses_necesarios = math.ceil(division)

print(f"Necesitamos arrendar {buses_necesarios} buses.") # Imprime 2

Si estás creando un carrito de compras y necesitas aplicar un descuento, y el precio final da $1490.99. Si quieres redondear el precio en favor del cliente (es decir, hacia abajo para cobrarle menos), ¿usarías math.ceil() o math.floor()?

🎲 Módulo random: El Sombrero Mágico

¿Qué es? Las computadoras son robots aburridos y predecibles. El módulo random permite inyectarle "azar" e imprevisibilidad a tus programas, simulando que tiras unos dados o sacas un papelito de un sombrero.

Función ¿Para qué sirve? (En español simple) Ejemplo
random.randint(min, max) Elige un número al azar entre el min y el max (ambos incluidos). ¡Igual que tirar un dado! random.randint(1, 6)
random.choice(lista) Elige al azar un solo elemento de una lista de opciones. (Como la ruleta de nombres). random.choice(['rojo', 'azul'])

Paso a Paso: ¿Qué almorzamos hoy?

📄 ruleta.py 
# Observa que aquí importamos SOLO choice y randint
from random import choice, randint

opciones = ["Pizza", "Sushi", "Hamburguesa", "Lentejas"]

# 1. Sacamos un papelito mágico del sombrero
comida = choice(opciones)
print(f"Hoy almorzaremos: {comida}")

# 2. Tiramos un dado para ver cuántas bebidas comprar
bebidas = randint(1, 5)
print(f"Y vamos a comprar {bebidas} bebidas.")

En un juego Gacha, sacar el personaje ultra-raro tiene 1% de probabilidad. Podrías crear un programa que tire randint(1, 100). Si el número resultante es igual a 1, ¡el jugador gana! ¿Cómo escribirías ese código con un if en tu cabeza?

🕰️ Módulo datetime: El Reloj de Pulsera

¿Qué es? Programar el tiempo es difícil (hay años bisiestos, zonas horarias, meses de 28 días). El módulo datetime hace todo el trabajo sucio por ti para que sepas qué fecha y hora es.

Función ¿Para qué sirve? (En español simple) Ejemplo
datetime.datetime.now() Pide la fecha y hora EXACTA de este mismo microsegundo. 2026-06-24 15:30:00.123456
variable.strftime(formato) "Traduce" la fecha robótica a un texto amigable (ej: Día/Mes/Año). 24/06/2026

Paso a Paso: El Ticket del Supermercado

📄 cajero.py 
# Le ponemos un apodo corto "dt" para no escribir datetime a cada rato
import datetime as dt

# 1. Mirar el reloj
ahora = dt.datetime.now()

# 2. Formatear la fecha. %d = Día, %m = Mes, %Y = Año
fecha_amigable = ahora.strftime("%d/%m/%Y")

print("--- BOLETA SUPERMERCADO ---")
print(f"Fecha de compra: {fecha_amigable}")

📁 Módulo os: Tus Ojos en el Computador

¿Qué es? "os" significa "Operating System" (Sistema Operativo). Le permite a Python abrir carpetas, ver qué archivos existen y borrar cosas, ¡como si hicieras doble clic con tu mouse!

Función ¿Para qué sirve? (En español simple) Ejemplo
os.listdir("ruta") Te entrega una lista con todos los archivos que hay dentro de una carpeta. ['foto.jpg', 'tarea.pdf']

Paso a Paso: El espía de carpetas

📄 espia.py 
import os

# "." significa "la carpeta actual donde estoy parado"
archivos = os.listdir(".")

print("He encontrado estos archivos en la carpeta:")
for nombre in archivos:
    print(f"- {nombre}")

🏗️ Tu Primer Proyecto Multi-Archivo

Un main.py de 1.000 líneas es una pesadilla de leer. La solución profesional es dividir el código. Cualquier archivo `.py` que tú crees, Python lo considera un módulo y te deja importarlo a otro archivo de tu misma carpeta.

Estudio de Caso: Sistema de Adopción de Mascotas 🐾

🐶

1. logica.py

Contiene solo las funciones aburridas del cálculo y datos.

def validar_edad(meses):
    return meses >= 2
👑

2. main.py (El Jefe)

Pide cosas por pantalla y usa las funciones del otro archivo.

from logica import validar_edad

# Bloque protector
if __name__ == "__main__":
    edad = int(input("Meses del perrito: "))
    if validar_edad(edad):
        print("¡Listo para adopción!")

🛡️ El Escudo de Python: if __name__ == "__main__":

Cuando un archivo hace import otro_archivo, Python en secreto lee ese archivo de arriba a abajo y ejecuta cualquier código que esté suelto.

Ese if gigante es tu escudo protector. Le dice a Python: "Oye, si alguien me está importando, entrégale mis funciones pero NO ejecutes el menú que está adentro de este if. SOLO ejecuta esto si un humano le dio doble clic a este archivo." ¡Úsalo siempre en tu main.py!

Errores Cuáticos (FAQ)

Cosas que los estudiantes suelen hacer pensando que van a funcionar... pero desatan el caos absoluto.

1. Nombrar tu archivo "random.py" (Shadowing) ▼

❌ Lo que intentas:

Creaste un archivo llamado random.py para probar la librería random. Adentro escribes import random y luego random.randint(1, 10). Al ejecutarlo, te da error: AttributeError: partially initialized module 'random' has no attribute 'randint'.

✅ Lo que pasó:

Python busca primero en la carpeta donde estás parado. Al hacer import random, en lugar de importar la librería oficial, ¡se importó a sí mismo! NUNCA nombres tus archivos con nombres de librerías famosas (math.py, random.py, os.py, datetime.py). Renómbralo a pruebas_random.py.

2. Pip install adentro del código Python ▼

❌ Lo que intentas:

# main.py
pip install requests
import requests
print("Listo")

✅ Lo que pasó:

pip install NO es código Python. Es un comando de tu sistema operativo (Terminal / CMD / Bash). Debes abrir la terminal, ejecutar pip install requests, esperar a que termine, y luego, en tu archivo .py, solo poner import requests.

3. Olvidar activar el Entorno Virtual (venv) ▼

❌ Lo que intentas:

Abres la terminal y corres tu código python main.py. Falla diciendo ModuleNotFoundError: No module named 'requests'. ¡Pero tú juras que lo instalaste ayer!

✅ Lo que pasó:

Lo instalaste adentro del entorno virtual (.venv). Cada vez que cierras la terminal (o abres una nueva en VSCode), el entorno virtual se desactiva. Tienes que volver a activarlo siempre antes de correr tu código o hacer más pip install (revisa si dice (.venv) al inicio de tu línea de comandos).

4. Importar todo y romper la RAM ▼

❌ Lo que intentas:

from math import *
from random import *

x = sqrt(10)
y = randint(1, 5)

✅ Lo que pasó:

Usar el asterisco * importa CIENTOS de funciones de golpe y las vuelca todas en tu archivo. Si math y random tuvieran una función con el mismo nombre, una sobrescribiría a la otra sin avisarte y te volverías loco buscando el bug. Sé explícito: importa solo lo que necesitas o importa el módulo completo.

5. Print intrusos al importar archivos ▼

❌ Lo que intentas:

En calculadora.py pusiste print("Esta es mi calcu") al principio para probar. Luego en main.py haces import calculadora. Cada vez que corres el main, sale ese texto en pantalla.

✅ Lo que pasó:

Al importar un archivo, Python lo "lee" entero y ejecuta cualquier cosa que esté suelta (fuera de funciones o clases). Mueve todo el código suelto (prints, inputs, ciclos) adentro del bloque if __name__ == "__main__": para que no estorbe cuando alguien importa tu archivo.

🧮 Más sobre math 🎲 Más sobre random 🕰️ Más sobre datetime 📁 Más sobre os

La librería math esconde herramientas matemáticas muy avanzadas. Aquí tienes algunas extra:

  • math.pow(x, y): Eleva `x` a la potencia de `y` (x elevado a y).
  • math.fabs(x): Devuelve el valor absoluto de un número (le quita el negativo).
  • math.factorial(x): Calcula el factorial (ej: 5! = 5*4*3*2*1).
  • math.trunc(x): Le "corta" los decimales a un número, sin redondear, solo los borra.

Si quieres hacer juegos, random será tu mejor amigo. Otras funciones geniales:

  • random.random(): Devuelve un número decimal (float) gigante entre 0.0 y 1.0 (ej: 0.83726...).
  • random.shuffle(lista): Toma una lista y la desordena por completo, ¡como barajar un mazo de cartas!
  • random.sample(lista, k): Elige `k` elementos únicos de una lista (ideal para un sorteo sin ganadores repetidos).

El manejo del tiempo es fundamental. Además de now(), puedes hacer lo siguiente:

  • Crear fechas manuales: dt.datetime(2026, 12, 31) para crear un objeto que represente fin de año.
  • Timetick (Timedeltas): Puedes sumar o restar días. Ej: hoy + dt.timedelta(days=5) te da la fecha de dentro de 5 días.
  • Formateo avanzado: %H:%M:%S en el strftime te da la hora, minutos y segundos exactos.

Con os puedes hacer scripts que ordenen tu computador automáticamente. Por ejemplo:

  • os.mkdir("carpeta"): Crea una carpeta nueva desde el código de Python.
  • os.remove("archivo.txt"): Borra un archivo (¡cuidado con este!).
  • os.path.exists("ruta"): Te devuelve True si un archivo o carpeta existe, y False si no. ¡Muy útil para no romper el programa!
  • os.rename("viejo.txt", "nuevo.txt"): Cambia el nombre de un archivo o lo mueve de carpeta.
