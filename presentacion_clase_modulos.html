La caja de herramientas

Imagina que compras un auto nuevo.

El auto viene listo para manejarse (volante, motor, ruedas).

Pero en la maleta, el fabricante te dejó una caja de herramientas roja gratuita.

No necesitas usarla siempre, pero si se pincha una rueda, abres la caja, sacas la gata hidráulica y resuelves el problema.

La Librería Estándar

Python funciona exactamente igual que ese auto.

Las funciones básicas como print() o len() son el volante y las ruedas: siempre están ahí.

Pero Python viene con una caja de herramientas gigante (gratis) llamada la Librería Estándar.

Contiene herramientas matemáticas, de fechas, de sistema, etc. Solo debemos "abrirlas" cuando las necesitemos.

¿Qué es un Módulo?

En el mundo real, un "módulo" de un mueble es una pieza independiente que puedes conectar a otras.

En Python, un módulo es simplemente un archivo de texto con código Python adentro.

La Librería Estándar está llena de estos módulos. Alguien ya escribió miles de líneas de código experto por nosotros, ¡y podemos usarlas gratis!

¿Qué significa "Importar"?

Si Python cargara TODA la librería estándar cada vez que haces un programa simple, tu computador se volvería lentísimo.

Por eso, usamos la palabra mágica import (importar).

Importar significa decirle a Python: "Oye, para este programa en específico, por favor anda a la maleta y tráeme la herramienta X".

Sintaxis 1: El import completo

Trae la caja entera de herramientas y ponla en la mesa.

# Traemos TODA la caja de matemáticas (módulo math)
import math

# Usamos la herramienta 'sqrt' (Raíz cuadrada) 
# Nota: Debemos escribir "math." antes de la herramienta
resultado = math.sqrt(25)
print(resultado) # Imprime 5.0

Ventaja: Sabes exactamente de dónde viene la herramienta.

Sintaxis 2: Traer algo específico

Si solo necesitas un martillo, no traigas toda la caja.

# "Desde matemáticas, impórtame SOLO la raíz cuadrada"
from math import sqrt

# Como solo trajimos el martillo, lo usamos directamente
# ¡Ya no escribimos "math." al principio!
resultado = sqrt(100)
print(resultado) # Imprime 10.0

Ventaja: Código más corto de escribir.

Sintaxis 3: El apodo (alias)

Si la caja tiene un nombre muy largo y te da pereza escribirlo.

# Importamos 'datetime' pero le ponemos el apodo 'dt'
import datetime as dt

# Ahora usamos 'dt' en lugar de escribir 'datetime'
hora_actual = dt.datetime.now()
print(hora_actual)

Ventaja: Te salva de la tendinitis en los dedos al programar.

Explorando: El módulo math 🧮

La calculadora científica de Python.

Útil cuando el +, -, *, / no son suficientes.

  • sqrt(x): Raíz cuadrada.
  • ceil(x): Redondea hacia ARRIBA (Techo).
  • floor(x): Redondea hacia ABAJO (Piso).
  • math.pi: El número Pi (3.14159...).

Ejemplo math: Los buses

Si tengo 41 alumnos y los buses son de 40 pasajeros, ¿cuántos buses contrato?

import math

alumnos = 41
capacidad = 40

division = alumnos / capacidad 
print(division) # Imprime 1.025 buses

# ¡No puedo contratar 1.025 buses! Redondeo hacia arriba (Techo)
buses_necesarios = math.ceil(division)

print("Buses a contratar:", buses_necesarios) # Imprime 2

Explorando: El módulo random 🎲

El sombrero mágico de Python.

Las computadoras son exactas y aburridas. Este módulo le da el factor sorpresa o "azar" a tus juegos y programas.

  • randint(min, max): Lanza un dado virtual entre dos números.
  • choice(lista): Elige al azar un elemento de una lista (como la ruleta).

Ejemplo random: El Gacha

from random import randint, choice

# 1. Un dado del 1 al 100
tirada = randint(1, 100)
print("Sacaste un:", tirada)

if tirada == 1:
    print("¡GANASTE EL PERSONAJE ULTRA-RARO!")
else:
    print("Sigue intentando...")

# 2. Elegir un enemigo al azar
enemigos = ["Orco", "Duende", "Dragón"]
rival = choice(enemigos)
print("¡Un", rival, "salvaje aparece!")

Explorando: El módulo datetime 🕰️

El reloj de pulsera de Python.

Calcular fechas es de las cosas más difíciles en programación (años bisiestos, zonas horarias). ¡Deja que Python lo haga!

  • datetime.now(): La hora y fecha exacta de este microsegundo.
  • strftime(formato): Traduce la fecha robot a un texto legible por humanos.

Ejemplo datetime: Boleta de Compra

import datetime as dt

⚠️ Error Común 1: "Shadowing"

Imagina que decides llamar a tu archivo random.py o math.py.

Al hacer import random, Python busca PRIMERO en tu misma carpeta.

¡Se importará a sí mismo en lugar de la librería real y todo explotará con errores raros!

REGLA DE ORO: Nunca nombres a tus archivos igual que los módulos de la librería estándar.

Repaso: ¿Qué es una Función Propia?

Ya usamos funciones hechas por expertos (math.sqrt). Ahora repasaremos cómo hacer las nuestras.

Una función es "empaquetar código" en una cajita con un nombre, para poder usarla muchas veces sin repetir código.

Las funciones se definen con la palabra def y tienen 4 formas posibles dependiendo de la información que ENTREGAS (parámetros) y la que RECIBES de vuelta (return).

1. Sin parámetros, sin return

No necesita información, ni devuelve un resultado matemático. Solo "hace una acción" repetitiva.

# DEFINICIÓN (La receta)
def mostrar_menu():
    print("--- MENÚ PRINCIPAL ---")
    print("1. Jugar")
    print("2. Salir")

# LLAMADA (Usar la receta)
mostrar_menu()
mostrar_menu() # Lo puedo llamar 100 veces sin re-escribir prints

2. Con parámetros, sin return

Necesita que le "pases" información (variables temporales), hace la acción, pero no te escupe un resultado matemático.

# 'nombre' es el parámetro (la variable vacía que espera un dato)
def saludar_usuario(nombre):
    print(f"¡Bienvenido al sistema, {nombre}!")

# Le pasamos el argumento ("Pedro" o "Ana") al llamarla
saludar_usuario("Pedro")
saludar_usuario("Ana")

3. Sin parámetros, con return

No necesita información extra, pero TE DEVUELVE (escupe) un valor para que lo guardes en una variable. Usa la palabra mágica return.

def pedir_numero_secreto():
    # Pide un número y lo devuelve al programa principal
    valor = 42
    return valor

# Como la función TIENE return, debo "atrapar" el valor en una variable
mi_secreto = pedir_numero_secreto()

print("El secreto devuelto es:", mi_secreto)

4. Con parámetros y con return

La más poderosa. Recibe materia prima, la procesa, y te devuelve el producto terminado.

# Recibe 'base' y 'altura'
def calcular_area_rectangulo(base, altura):
    area = base * altura
    return area # Escupe el resultado matemático

# Pasamos 5 y 10. Atrapamos el 50 devuelto en 'resultado'
resultado = calcular_area_rectangulo(5, 10)
print("El área es:", resultado)

# ¡Podemos reutilizarla al infinito con distintos números!

El Salto a Multi-Archivo 🏗️

Hasta ahora, todos tus programas han sido un único archivo larguísimo.

Imagina un juego profesional (Mario Bros, GTA). Tienen millones de líneas de código. Si estuviera todo en un main.py, sería imposible de leer.

Solución: Dividimos el programa en varios archivos lógicos (ej: jugador.py, enemigos.py, mapa.py).

¿Cómo unimos los archivos?

¡Exactamente igual que como importamos la librería estándar!

Si tú creas un archivo llamado utilidades.py que tiene una función limpiar_texto()...

...Cualquier otro archivo en la misma carpeta puede hacer:

from utilidades import limpiar_texto

¡Tus propios archivos se han convertido en módulos!

⚠️ Error Común 2: El Directorio

Para que main.py pueda importar a utilidades.py de forma simple, AMBOS archivos deben estar guardados exactamente en la misma carpeta.

✅ BIEN

📁 Mi_Proyecto/
  📄 main.py
  📄 utilidades.py

❌ MAL (Dará Error)

📁 Descargas/
  📄 main.py
📁 Documentos/
  📄 utilidades.py

Ejemplo: Proyecto Multi-Archivo 💻

Vamos a construir un sistema para un cajero automático muy simple.

Tendrá dos archivos en la misma carpeta:

  • matematicas_banco.py: Tendrá las funciones con cálculos (las reglas de negocio).
  • main.py: El archivo principal que interactúa con el usuario y usa las otras funciones.

Archivo 1: matematicas_banco.py

# ESTE ARCHIVO SOLO TIENE FUNCIONES (Módulo)

# Función 1: Sin params, con return
def obtener_interes_diario():
    return 1.05 # Te devuelve 5% de interés

# Función 2: Con params, con return
def calcular_nuevo_saldo(saldo_actual, monto_retiro):
    nuevo_saldo = saldo_actual - monto_retiro
    return nuevo_saldo

Si ejecuto este archivo directamente, no hace nada visible porque solo definió herramientas, no las usó.

Archivo 2: main.py

# 1. Importo la librería estándar
import datetime as dt
# 2. Importo MI PROPIO MÓDULO (mis funciones)
from matematicas_banco import obtener_interes_diario, calcular_nuevo_saldo

saldo = 10000
print("--- BIENVENIDO AL BANCO DUOC ---")
print("Fecha:", dt.datetime.now().strftime("%d/%m"))

# Uso la función de mi otro archivo
interes = obtener_interes_diario()
print("El interés de hoy es:", interes)

retiro = int(input("¿Cuánto desea retirar? "))
# Uso mi otra función para el cálculo matemático
saldo = calcular_nuevo_saldo(saldo, retiro)

print("Su nuevo saldo es:", saldo)

🧠 Check de Comprensión

En el código del banco recién visto, el programador dividió el proyecto en matematicas_banco.py y main.py.

¿Qué ganamos haciendo esto en lugar de poner los dos `def` directo en el `main.py`?

👉 Clic aquí para revelar respuestas posibles
1. Orden: El main.py se mantiene limpio, enfocado solo en leer inputs y mostrar prints.

2. Reutilización: Si mañana creamos una app web para el banco en app.py, podemos hacer `from matematicas_banco import...` y usar la misma lógica matemática sin copiar y pegar código.

Resumen Visual de la Clase

  • 📦 Módulo: Un archivo .py con código (herramientas).
  • 🧰 Librería Estándar: Módulos gratis que ya vienen en Python (`math`, `random`, `datetime`).
  • 🚚 import: La acción de traer herramientas de un módulo a mi archivo.
  • ⚙️ Funciones propias: Bloques `def` que creamos nosotros. Pueden recibir (parámetros) y escupir (return).
  • 🏗️ Proyectos Multi-archivo: Crear varios archivos .py en una misma carpeta e importarlos entre sí para ordenar proyectos gigantes.
