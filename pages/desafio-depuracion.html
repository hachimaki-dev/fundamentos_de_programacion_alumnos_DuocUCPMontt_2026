Desafío 1 — Registro de Astronautas

La Agencia Espacial Internacional necesita un sistema para registrar astronautas en su nueva misión. El programa debe solicitar datos de cada candidato y clasificarlos según su rendimiento.

📋 Requisitos del programa:

  • Preguntar cuántos astronautas se van a registrar (debe ser un entero positivo mayor a 0).
  • Para cada astronauta, pedir su nombre (no vacío) y su puntaje de aptitud (entero entre 1 y 100 inclusive).
  • Si el puntaje es mayor o igual a 80, clasificar como "Apto para misión". Si es menor a 80, clasificar como "En entrenamiento".
  • Al finalizar, mostrar cuántos quedaron "Apto para misión" y cuántos "En entrenamiento".
  • También mostrar el promedio general de puntajes redondeado a 2 decimales.

💻 Código a depurar:

registro_astronautas.py Python 3 
print("=== AGENCIA ESPACIAL INTERNACIONAL ===")
print("Sistema de Registro de Astronautas")

while True:
    try:
        cantidad = int(input("¿Cuántos astronautas registrar? "))
        if cantidad > 0:
            break
        print("Debe ser un número positivo.")
    except ValueError:
        print("Entrada inválida. Ingresa un número entero.")

aptos = 0
entrenamiento = 0
suma_puntajes = 0

for i in range(cantidad):
    print(f"\n--- Astronauta {i+1} ---")

    while True:
        nombre = input("Nombre del astronauta: ").strip()
        if len(nombre) > 0:
            break
        print("El nombre no puede estar vacío.")

    while True:
        try:
            puntaje = int(input("Puntaje de aptitud (1-100): "))
            if 1 <= puntaje <= 100:
                break
            print("El puntaje debe estar entre 1 y 100.")
        except ValueError:
            print("Ingresa un número entero válido.")

    suma_puntajes += puntaje

    if puntaje > 80:
        print(f"→ {nombre}: Apto para misión")
        aptos += 1
    else:
        print(f"→ {nombre}: En entrenamiento")
        entrenamiento += 1

promedio = suma_puntajes / aptos
print(f"\n=== RESUMEN DE LA MISIÓN ===")
print(f"Aptos para misión: {aptos}")
print(f"En entrenamiento: {entrenamiento}")
print(f"Promedio general: {promedio}")

Desafío 2 — Clasificación de Aprendices de Magia

La Academia Arcana necesita clasificar a sus nuevos aprendices en tres casas según su poder mágico. El sistema debe registrar cada estudiante y generar estadísticas al final.

📋 Requisitos del programa:

  • Pedir cuántos aprendices se registrarán (entero positivo).
  • Para cada aprendiz pedir su nombre mágico (mínimo 3 caracteres) y su nivel de poder (entero entre 1 y 100).
  • Clasificación por poder: 71 a 100 → "Casa del Fénix", 41 a 70 → "Casa del Grifo", 1 a 40 → "Casa del Búho".
  • Al finalizar mostrar cuántos aprendices hay en cada casa.
  • Mostrar el nombre y poder del aprendiz más poderoso (el de mayor puntaje).

💻 Código a depurar:

academia_magia.py Python 3 
print("✨ ACADEMIA ARCANA — Clasificación de Aprendices ✨")

while True:
    try:
        cantidad = int(input("¿Cuántos aprendices registrar? "))
        if cantidad > 0:
            break
        print("Ingresa un número mayor a 0.")
    except ValueError:
        print("Entrada inválida.")

fenix = 0
grifo = 0
buho = 0
mejor_nombre = ""
mejor_poder = 0

for i in range(cantidad):
    print(f"\n--- Aprendiz {i+1} ---")

    while True:
        nombre = input("Nombre mágico: ").strip()
        if len(nombre) >= 3:
            break
        print("El nombre debe tener al menos 3 caracteres.")

    while True:
        try:
            poder = int(input("Nivel de poder (1-100): "))
            if 1 <= poder <= 100:
                break
            print("Debe estar entre 1 y 100.")
        except ValueError:
            print("Ingresa un entero válido.")

    if poder >= 71:
        print(f"→ {nombre} ingresa a la Casa del Fénix 🔥")
        fenix += 1
    elif poder >= 40:
        print(f"→ {nombre} ingresa a la Casa del Grifo 🦅")
        grifo += 1
    else:
        print(f"→ {nombre} ingresa a la Casa del Búho 🦉")
        buho += 1

    if poder > mejor_poder:
        mejor_nombre = nombre

print(f"\n✨ RESULTADOS DE LA CLASIFICACIÓN ✨")
print(f"Casa del Fénix: {fenix}")
print(f"Casa del Grifo: {grifo}")
print(f"Casa del Búho: {buho}")
print(f"Aprendiz más poderoso: {mejor_nombre} con poder {mejor_poder}")

Desafío 3 — Monitoreo Ambiental de la Estación Polar

La Estación Científica Antártica necesita un sistema de monitoreo que registre lecturas de temperatura durante el día y genere un informe con alertas y estadísticas.

📋 Requisitos del programa:

  • Pedir cuántas lecturas de temperatura se tomarán (entero positivo).
  • Para cada lectura, pedir la hora (texto, no vacío) y la temperatura en °C (entero entre -60 y 50 inclusive).
  • Si la temperatura es menor a -20, mostrar "⚠️ ALERTA: Temperatura crítica" y contar como alerta.
  • Almacenar cada lectura como un diccionario {"hora": ..., "temp": ..., "alerta": True/False} en una lista.
  • Al finalizar, mostrar: la temperatura mínima, la temperatura máxima, el promedio redondeado a 1 decimal, y la cantidad de alertas.

💻 Código a depurar:

monitoreo_polar.py Python 3 
print("🔬 ESTACIÓN CIENTÍFICA ANTÁRTICA")
print("Sistema de Monitoreo Ambiental")

while True:
    try:
        num_lecturas = int(input("¿Cuántas lecturas registrar? "))
        if num_lecturas > 0:
            break
        print("Debe ser mayor a 0.")
    except ValueError:
        print("Ingresa un número entero.")

lecturas = []
alertas = 0
temp_min = 50
temp_max = -60
suma_temps = 0

for i in range(num_lecturas):
    print(f"\n--- Lectura {i+1} ---")

    while True:
        hora = input("Hora de la lectura: ").strip()
        if len(hora) > 0:
            break
        print("La hora no puede estar vacía.")

    while True:
        try:
            temp = int(input("Temperatura (°C): "))
            if -60 <= temp <= 50:
                break
            print("Debe estar entre -60 y 50.")
        except ValueError:
            print("Ingresa un entero válido.")

    es_alerta = False
    if temp <= -20:
        print("⚠️ ALERTA: Temperatura crítica")
        alertas += 1
        es_alerta = True

    if temp < temp_min:
        temp_min = temp
    if temp > temp_max:
        temp_max = temp

    registro = {"hora": hora, "temp": temp, "alerta": es_alerta}
    lecturas.append(registro)

promedio = suma_temps / num_lecturas

print(f"\n🔬 INFORME DEL DÍA")
print(f"Lecturas registradas: {num_lecturas}")
print(f"Temperatura mínima: {temp_min}°C")
print(f"Temperatura máxima: {temp_max}°C")
print(f"Promedio: {promedio}°C")
print(f"Alertas críticas: {alertas}")

print(f"\n--- Detalle de Alertas ---")
for r in lecturas:
    if r["alerta"]:
        print(f"Hora: {r['hora']} | Temp: {r['temp']}°C")

Desafío 4 — Torneo eSports: Liga de Campeones

La Liga de Campeones eSports necesita un sistema para registrar jugadores, calcular sus puntajes y generar un ranking final con clasificación por divisiones.

📋 Requisitos del programa:

  • Pedir cuántos jugadores participan (entero positivo, mínimo 2).
  • Para cada jugador pedir: gamertag (mínimo 3 caracteres, sin espacios) y 3 puntajes de rondas (enteros entre 0 y 100 cada uno).
  • Calcular el puntaje final como el promedio de las 3 rondas.
  • Clasificación: puntaje final ≥ 80 → "División Diamante", ≥ 50 → "División Oro", < 50 → "División Bronce".
  • Guardar cada jugador como diccionario en una lista: {"gamertag": ..., "puntajes": [...], "final": ..., "division": ...}.
  • Al finalizar mostrar: cantidad de jugadores por división, el gamertag del ganador (mayor puntaje final), y el puntaje promedio general del torneo redondeado a 2 decimales.

💻 Código a depurar:

torneo_esports.py Python 3 
print("🎮 LIGA DE CAMPEONES — Torneo eSports")

while True:
    try:
        num_jugadores = int(input("¿Cuántos jugadores participan? "))
        if num_jugadores >= 2:
            break
        print("Se necesitan al menos 2 jugadores.")
    except ValueError:
        print("Ingresa un número entero.")

jugadores = []
diamante = 0
oro = 0
bronce = 0
mejor_gamertag = ""
mejor_puntaje = 0
suma_general = 0

for i in range(num_jugadores):
    print(f"\n--- Jugador {i+1} ---")

    while True:
        tag = input("Gamertag: ").strip()
        if len(tag) >= 3 and " " not in tag:
            break
        print("El gamertag debe tener al menos 3 caracteres y sin espacios.")

    puntajes = []
    for ronda in range(3):
        while True:
            try:
                pts = int(input(f"Puntaje ronda {ronda+1} (0-100): "))
                if 0 <= pts <= 100:
                    puntajes.append(pts)
                    break
                print("Debe estar entre 0 y 100.")
            except ValueError:
                print("Ingresa un entero válido.")

    puntaje_final = sum(puntajes) / 2

    if puntaje_final >= 80:
        division = "División Diamante"
        diamante += 1
    elif puntaje_final > 50:
        division = "División Oro"
        oro += 1
    else:
        division = "División Bronce"
        bronce += 1

    print(f"→ {tag}: Puntaje final {puntaje_final:.2f} — {division}")

    if puntaje_final > mejor_puntaje:
        mejor_puntaje = puntaje_final
        mejor_gamertag = tag

    jugador = {"gamertag": tag, "puntajes": puntajes, "final": puntaje_final, "division": division}
    jugadores.append(jugador)
    suma_general += puntaje_final

promedio_torneo = suma_general / len(jugadores)

print(f"\n🏆 RESULTADOS DEL TORNEO")
print(f"División Diamante: {diamante} jugadores")
print(f"División Oro: {oro} jugadores")
print(f"División Bronce: {bronce} jugadores")
print(f"Ganador del torneo: {mejor_gamertag}")
print(f"Promedio general del torneo: {promedio_torneo}")

Desafío 5 — Sistema de Gestión de Colonos

La Colonia Terranova en Marte necesita un sistema con menú interactivo para registrar colonos, buscarlos y generar reportes de distribución por sector.

📋 Requisitos del programa:

  • Usar un menú interactivo con 4 opciones que se repite hasta que el usuario elija Salir.
  • Opción 1 — Registrar colono: Pedir nombre (no vacío), edad (entero entre 18 y 65 inclusive) y especialidad ("ingenieria", "medicina" o "ciencia"). Guardar como diccionario en una lista.
  • Opción 2 — Buscar colono: Pedir un nombre y buscarlo sin distinguir mayúsculas/minúsculas. Si se encuentra, mostrar todos sus datos. Si no, mostrar "Colono no encontrado.".
  • Opción 3 — Reporte: Mostrar total de colonos, cuántos hay por especialidad y la edad promedio redondeada a 1 decimal. Si no hay colonos, mostrar "No hay colonos registrados.".
  • Opción 4 — Salir: Terminar el programa con un mensaje de despedida.

💻 Código a depurar:

colonia_marte.py Python 3 
print("🏙️ COLONIA TERRANOVA — Sistema de Gestión")

colonos = []

while True:
    print("\n=== MENÚ PRINCIPAL ===")
    print("1. Registrar colono")
    print("2. Buscar colono")
    print("3. Reporte de la colonia")
    print("4. Salir")

    opcion = input("Selecciona una opción: ")

    if opcion == "1":
        print("\n--- Registro de Colono ---")

        while True:
            nombre = input("Nombre: ").strip()
            if len(nombre) > 0:
                break
            print("El nombre no puede estar vacío.")

        while True:
            try:
                edad = int(input("Edad (18-65): "))
                if 18 <= edad <= 65:
                    break
                print("La edad debe estar entre 18 y 65.")
            except ValueError:
                print("Ingresa un número entero.")

        especialidades_validas = ["ingenieria", "medicina", "ciencia"]
        while True:
            especialidad = input("Especialidad (ingenieria/medicina/ciencia): ").strip().lower()
            if especialidad in especialidades_validas:
                break
            print("Especialidad no válida. Elige: ingenieria, medicina o ciencia.")

        colono = {"nombre": nombre, "edad": edad, "especialidad": especialidad}
        colonos.append(colono)
        print(f"✅ Colono {nombre} registrado exitosamente.")

    elif opcion == "2":
        busqueda = input("Nombre del colono a buscar: ").strip()
        encontrado = False

        for c in colonos:
            if c["nombre"] == busqueda:
                print(f"\n🔍 Colono encontrado:")
                print(f"   Nombre: {c['nombre']}")
                print(f"   Edad: {c['edad']}")
                print(f"   Especialidad: {c['especialidad']}")
                encontrado = True

        if not encontrado:
            print("Colono no encontrado.")

    elif opcion == "3":
        print("\n📊 REPORTE DE LA COLONIA")

        total = len(colonos)
        print(f"Total de colonos: {total}")

        ing = 0
        med = 0
        cie = 0
        suma_edades = 0

        for c in colonos:
            suma_edades += c["edad"]
            if c["especialidad"] == "ingenieria":
                ing += 1
            elif c["especialidad"] == "medicina":
                med += 1
            elif c["especialidad"] == "ciencia":
                cie += 1

        print(f"Ingeniería: {ing}")
        print(f"Medicina: {med}")
        print(f"Ciencia: {cie}")

        promedio_edad = suma_edades / total
        print(f"Edad promedio: {round(promedio_edad, 1)}")

    elif opcion == "4":
        print("Cerrando sistema. ¡Hasta la próxima misión!")
        break

    else:
        print("Opción no válida. Elige entre 1 y 4.")

Desafío 6 — Sistema del Gremio de Aventureros

El Gran Gremio de Aventureros necesita un sistema completo para registrar misiones completadas por sus miembros, calcular recompensas, clasificar rangos y generar estadísticas finales.

📋 Requisitos del programa:

  • Pedir cuántos aventureros se registrarán (entero positivo).
  • Para cada aventurero pedir: nombre (mínimo 2 caracteres), cantidad de misiones completadas (entero entre 1 y 50) y nivel de dificultad promedio de sus misiones (entero entre 1 y 10).
  • Calcular las monedas de oro ganadas = misiones × dificultad × 15.
  • Clasificar por rango según monedas: ≥ 3000 → "Rango Legendario", ≥ 1500 → "Rango Veterano", ≥ 500 → "Rango Novato", < 500 → "Rango Aprendiz".
  • Guardar cada aventurero en una lista de diccionarios con claves: nombre, misiones, dificultad, oro, rango.
  • Al finalizar mostrar: total de aventureros, cantidad por cada rango, el aventurero con más oro (nombre y cantidad), el total de oro generado por el gremio y el promedio de misiones redondeado a 1 decimal.

💻 Código a depurar:

            break

        print("Ingresa un entero válido.")

veteranos = 0

mejor_oro = 0

    while True:

            break

    while True:

            misiones = int(input("Misiones completadas (1-50): "))

                break
            print("Debe estar entre 1 y 50.")

print(f"Promedio de misiones: {promedio_misiones}")

🚀 Pauta — Desafío 1: Registro de Astronautas

1 Condición de clasificación incorrecta

Línea afectada: if puntaje > 80:

Problema: El requisito dice que un puntaje ≥ 80 (mayor o igual) clasifica como "Apto para misión", pero el código usa > (estrictamente mayor). Un astronauta con exactamente 80 puntos quedaría clasificado como "En entrenamiento" cuando debería ser "Apto".

💥 Impacto: Astronautas con puntaje 80 son incorrectamente clasificados como "En entrenamiento".

Corrección: Cambiar if puntaje > 80: → if puntaje >= 80:

2 Promedio calculado con divisor incorrecto

Línea afectada: promedio = suma_puntajes / aptos

Problema: El requisito pide el "promedio general de puntajes", lo que significa dividir la suma total entre todos los astronautas (cantidad), no solo los aptos. Si ningún astronauta es apto (aptos = 0), además produce un ZeroDivisionError.

💥 Impacto: El promedio es incorrecto (se calcula solo sobre los aptos) y puede causar un crash si todos quedan "En entrenamiento".

Corrección: Cambiar promedio = suma_puntajes / aptos → promedio = suma_puntajes / cantidad

3 Promedio no redondeado a 2 decimales

Línea afectada: print(f"Promedio general: {promedio}")

Problema: El requisito exige que el promedio se muestre redondeado a 2 decimales, pero el código imprime el valor sin formatear.

💥 Impacto: Se muestran valores con muchos decimales, incumpliendo la especificación de presentación.

Corrección: Cambiar {promedio} → {promedio:.2f} o usar round(promedio, 2)

        novatos += 1
    else:
        rango = "Rango Aprendiz"
        aprendices += 1

    print(f"→ {nombre}: {oro} monedas de oro — {rango}")

    if oro > mejor_oro:  # FIX 3: > en lugar de >=
        mejor_nombre = nombre
        mejor_oro = oro

    aventurero = {"nombre": nombre, "misiones": misiones, "dificultad": dificultad, "oro": oro, "rango": rango}
    aventureros.append(aventurero)
    total_oro += oro
    suma_misiones += misiones

promedio_misiones = suma_misiones / len(aventureros)
