Boss Final: Ejercicio Integrador

Aquí usarás todos los patrones que practicaste en los 7 niveles. Desarrolla el sistema completo en Python. ¡Tú puedes!

📝 Enunciado

Desarrolla un programa en Python que implemente un sistema de gestión de pociones mágicas de un videojuego. Todo el comportamiento debe organizarse mediante funciones bien definidas. El programa debe incluir un menú interactivo, validaciones de entrada, una operación de actualización masiva y uso de funciones separadas por responsabilidad.

📦 Datos que debe manejar el sistema

El sistema trabaja con una colección de pociones. Esta colección debe existir desde que el programa inicia como una lista vacía y estar disponible durante toda la ejecución. Cada poción se representa como un diccionario con estos campos:

Campo Qué representa Restricciones
"nombre" Nombre de la poción No vacío ni solo espacios en blanco
"poder" Nivel de poder de la poción Número entero mayor que 0
"activa" ¿La poción está activa? False al registrar. No se pide al usuario. Cambia a True cuando se ejecute la opción 4, si el poder es ≥ 5.

📋 Menú del sistema

El menú aparece en pantalla en cada vuelta del ciclo. El usuario elige una opción numérica. Debe implementarse con dos funciones separadas: una que muestre las opciones (sin recibir ni retornar nada) y otra que lea y retorne la opción validada.

========== MENÚ PRINCIPAL ==========
1. Agregar poción
2. Buscar poción
3. Eliminar poción
4. Activar pociones
5. Mostrar pociones
6. Salir
=====================================

⚙️ Qué debe hacer cada opción

Opción 1 — Agregar poción

Solicita nombre y poder. Valida cada campo con una función de validación distinta. Si algún dato no cumple, informa al usuario y no registra la poción. Solo cuando todos son válidos, crea el diccionario (con "activa": False) y lo agrega a la lista. Los mensajes de error se muestran en esta función, no dentro de las validaciones.

Opción 2 — Buscar poción

Solicita un nombre y busca en la lista. Define una función de búsqueda que reciba la lista y el nombre, retorne la posición si la encuentra o -1 si no existe. El programa principal decide qué hacer: si encontró, muestra los datos; si no, informa.

Opción 3 — Eliminar poción

Solicita el nombre. Reutiliza la función de búsqueda de la opción 2. Si retorna posición válida, elimina con .pop(). Si retorna -1, muestra: "La poción 'nombre' no se encuentra registrada."

Opción 4 — Activar pociones

Recorre TODA la lista y actualiza "activa" según la regla: si poder ≥ 5 → True; si no → False. Define una función que reciba la lista y aplique la regla a cada elemento.

Opción 5 — Mostrar pociones

Primero llama a la función de activación (opción 4), luego recorre la lista mostrando cada poción con el formato:

=== LISTA DE POCIONES ===
Nombre: Elixir de Fuego
Poder: 8
Estado: ACTIVA
**************************
Nombre: Gota de Rocío
Poder: 3
Estado: INACTIVA
**************************

Opción 6 — Salir

Termina la ejecución de forma limpia. Muestra: "Gracias por usar el sistema. Vuelva pronto"

💡 Pistas — Conecta cada parte con lo que aprendiste

Cada pista te remite al nivel donde practicaste ese patrón exacto.

Nivel 1

La lista empieza vacía: pociones = []. Cada poción es un diccionario con 3 campos. El campo "activa" siempre inicia en False.

Nivel 2

Para validar el nombre usa .strip() != "". La función de validación solo retorna True/False — los mensajes de error van en la función que la llama.

Nivel 3

Para validar el poder: texto.isdigit() and int(texto) > 0. Recuerda que input() siempre retorna un string.

Nivel 4

La función de búsqueda recorre con for i in range(len(lista)). Si encuentra, return i. Después del for: return -1. No imprime mensajes.

Nivel 5

Para eliminar: llama a buscar_pocion(), verifica que != -1, y luego lista.pop(posicion). No escribas otro for — reutiliza.

Nivel 6

Para actualizar: for p in lista: p["activa"] = p["poder"] >= 5. Funciona sin return porque los diccionarios son mutables. Recuerda el else: False.

Nivel 7

while True + break en la opción 6. Dos funciones separadas: mostrar_menu() y leer_opcion(). El dispatcher usa if/elif.
