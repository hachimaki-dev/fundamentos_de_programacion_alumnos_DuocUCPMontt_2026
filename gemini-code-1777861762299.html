Gestión de Excepciones

El arte de fallar con elegancia. En sistemas electorales, un error no gestionado es un riesgo democrático. Aprende a capturar el caos y convertirlo en control.

Lógica del Sistema

Código Ineficiente (Antes) Peligro de Crash 
# Sin gestión
votos = int(input("Votos: "))
mesas = int(input("Mesas: "))
promedio = votos / mesas
print(f"Resultado: {promedio}")
Código Robusto (Después) Protegido 
try:
    votos = int(input("Votos: "))
    promedio = votos / mesas_abiertas
except ValueError:
    print("Error: Ingrese solo números")
except ZeroDivisionError:
    print("Error: No hay mesas abiertas")
finally:
    cerrar_conexion_db()
