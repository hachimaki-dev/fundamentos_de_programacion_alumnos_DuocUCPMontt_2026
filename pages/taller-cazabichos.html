🪲 Taller: Sistema Cazabichos

Aprende a estructurar un sistema CRUD completo en consola utilizando funciones independientes, listas de diccionarios y validaciones de datos estrictas.

Descripción General 🎯

Desarrolla un programa en Python que implemente un sistema de registro de bichos para una aplicación de "Cazabichos", donde todo el comportamiento se organice mediante funciones bien definidas. El programa debe incluir un menú interactivo, validaciones de entrada, operaciones lógicas (decisiones y comparaciones) y uso de funciones separadas.

1. Datos que debe manejar el sistema 📦

El sistema trabaja con una colección de bichos capturados. Esta colección debe existir desde que el programa inicia y estar disponible durante toda la ejecución. Cada vez que se registra un bicho, se incorpora a esa colección como un nuevo elemento.

Cada bicho se representa como un diccionario con 4 campos asociados: especie, tamaño, peligrosidad y peligroso. La siguiente tabla resume los campos de cada registro:

Campo Qué representa Restricciones de validación
"especie" Nombre de la especie del bicho str. No vacío ni solo espacios en blanco.
"tamaño" Tamaño del bicho, en centímetros int. Número entero mayor que cero.
"peligrosidad" Nivel de peligrosidad (1.0–10.0) float. Número decimal entre 1.0 y 10.0 (incluidos).
"peligroso" ¿Es considerado un bicho peligroso? bool. Inicia en False al registrar. No se solicita al usuario, el sistema lo calcula automáticamente en base a la peligrosidad.

Cada diccionario se guarda dentro de una lista. La lista es la colección general; los diccionarios son los bichos individuales dentro de ella. El programa comienza con la lista vacía y la va llenando a medida que se registran nuevos bichos.

2. Lo que debe hacer el sistema ⚙️

El sistema se controla desde un menú que aparece en pantalla cada vez que el usuario termina una acción. El usuario elige una opción numérica, el programa ejecuta la tarea correspondiente y vuelve a mostrar el menú. Esto se repite hasta que el usuario elige salir.

El menú tiene seis opciones:

========== MENÚ PRINCIPAL ==========
1. Agregar bicho
2. Buscar bicho
3. Eliminar bicho
4. Actualizar estados
5. Mostrar bichos
6. Salir
=====================================

💡 Regla de Arquitectura

Debes definir dos funciones separadas para el menú: una que muestre las opciones en pantalla (sin recibir ni retornar nada) y otra que lea y retorne la opción elegida por el usuario (sin recibir nada, retornando el número validado). Ambas funciones deben invocarse en cada vuelta del ciclo.

Detalle de las Opciones del Menú:

1Agregar bicho

El sistema solicita al usuario la especie, el tamaño y el nivel de peligrosidad del bicho. Antes de guardar el registro, verifica que cada dato cumpla su condición:

  • La especie no puede estar vacía ni ser solo espacios en blanco.
  • El tamaño debe ser un número entero mayor que cero.
  • La peligrosidad debe ser un número decimal entre 1.0 y 10.0.

Si algún dato no cumple la condición, el sistema informa al usuario y no registra al bicho. Solo cuando todos los datos son válidos se crea el diccionario y se agrega a la lista.

Estructura requerida: Define una función que reciba la lista como parámetro. Dentro de ella se solicitan los datos y se llama a una función de validación distinta para cada campo. Los mensajes de error se muestran en esta función de acción, no dentro de las funciones de validación.
2Buscar bicho

El sistema solicita una especie al usuario y recorre la lista buscando un registro cuyo campo especie coincida exactamente con el ingresado. Si lo encuentra, muestra la posición en la que está y sus datos. Si no existe ningún registro con esa especie, informa al usuario.

Estructura requerida: Define una función que reciba la lista y la especie a buscar como parámetros. La función recorre la lista y retorna la posición del registro encontrado, o -1 si no existe. Es el programa principal quien recibe ese valor y decide qué hacer con él.
3Eliminar bicho

El sistema solicita la especie del bicho que se desea eliminar. Para localizarlo, llama a la función de búsqueda de la opción anterior, pasándole la lista y la especie ingresada. Si la función retorna una posición válida, el sistema elimina el registro en esa posición. Si retorna -1, informa con el mensaje: 

El bicho 'especie' no se encuentra registrado.
4Actualizar estados

El sistema recorre la lista completa de bichos y actualiza el campo "peligroso" de cada registro según su peligrosidad: si la peligrosidad es mayor o igual a 7.0, el campo pasa a True; si es menor, queda en False. Esta operación afecta a todos los registros de la lista sin excepción.

Estructura requerida: Define una función que reciba la lista como parámetro y aplique esa regla a cada elemento.
5Mostrar bichos

El sistema primero actualiza los estados de todos los bichos haciendo el llamado a la función anterior (Opción 4), luego recorre la lista mostrando los datos de cada bicho. El formato de salida es el siguiente: 

=== LISTA DE BICHOS ===

Especie: Escarabajo Rinoceronte
Tamaño: 15
Peligrosidad: 8.5
Estado: PELIGROSO
********************************************
Especie: Mariquita
Tamaño: 1
Peligrosidad: 2.0
Estado: NO PELIGROSO
*********************************************
6Salir

El sistema termina la ejecución de forma limpia, sin errores. El ciclo del menú se detiene y el programa finaliza con un mensaje de despedida: 

"Gracias por usar el Cazabichos. ¡Hasta la próxima expedición!"

A continuación, se detalla una tabla interactiva con patrones comunes de lógica y código que te resultarán de gran utilidad para enfrentarte al desarrollo de este ejercicio.

1 Estado Inicial: Inicializar la lista Estructura global

La lista que contendrá los diccionarios debe definirse una sola vez en el programa principal antes de entrar al menú. 

# Al inicio del archivo principal
lista_bichos = []
2 Validación de Cadenas de Texto Especie

Para verificar si un string no está vacío ni contiene únicamente espacios en blanco, se limpia con .strip() y se evalúa su longitud. 

def validar_especie(especie):
    # .strip() elimina espacios al inicio y al final
    especie_limpia = especie.strip()
    # Si la cadena no quedó vacía, es válida
    if especie_limpia != "":
        return True
    else:
        return False
3 Validación de Números Enteros Tamaño

Para validar enteros, podemos intentar la conversión usando try/except ValueError y verificar que cumpla con el criterio solicitado (mayor que 0). 

def validar_tamano(tamano_str):
    try:
        tamano = int(tamano_str)
        if tamano > 0:
            return True
        else:
            return False
    except ValueError:
        # Si no se pudo convertir a entero
        return False
4 Validación de Decimales y Rango Peligrosidad

Similar a los enteros, se intenta la conversión a float y luego se valida si está dentro del rango inclusivo. 

def validar_peligrosidad(peligrosidad_str):
    try:
        peligrosidad = float(peligrosidad_str)
        if 1.0 <= peligrosidad <= 10.0:
            return True
        else:
            return False
    except ValueError:
        return False
5 Agregar Registro: Lógica de Flujo Secuencial Mutabilidad

Al agregar, solicitamos los datos uno por uno. Si un dato no pasa su validación correspondiente, interrumpimos el flujo de inmediato usando return para no seguir preguntando datos innecesariamente. 

def agregar_bicho(lista):
    especie = input("Ingrese especie del bicho: ")
    if not validar_especie(especie):
        print("Error: La especie no puede estar vacía.")
        return # Sale de la función sin agregar nada
        
    tamano_str = input("Ingrese tamaño en cm: ")
    if not validar_tamano(tamano_str):
        print("Error: El tamaño debe ser un número entero mayor a 0.")
        return
        
    peligrosidad_str = input("Ingrese nivel de peligrosidad (1.0 - 10.0): ")
    if not validar_peligrosidad(peligrosidad_str):
        print("Error: Peligrosidad debe ser un número decimal entre 1.0 y 10.0.")
        return
        
    # Si todo es correcto, creamos el diccionario e insertamos en la lista
    bicho = {
        "especie": especie.strip(),
        "tamaño": int(tamano_str),
        "peligrosidad": float(peligrosidad_str),
        "peligroso": False # Por defecto inicia en False
    }
    lista.append(bicho)
    print("¡Bicho registrado exitosamente!")
6 Búsqueda Secuencial en Lista de Diccionarios Búsqueda

Para buscar, recorremos la lista mediante sus índices. Comparamos la clave (por ejemplo, con .lower() para evitar problemas de mayúsculas/minúsculas). Retornamos la posición del índice encontrado o -1. 

def buscar_bicho(lista, especie_buscada):
    # Convertimos a minúsculas para una comparación más flexible
    buscar = especie_buscada.lower().strip()
    for i in range(len(lista)):
        if lista[i]["especie"].lower() == buscar:
            return i # Retorna el índice inmediatamente
    return -1 # Si terminó el ciclo y no encontró nada
7 Eliminación por Índice Eliminar

Reutilizamos la función de búsqueda para obtener la posición. Si es válida, removemos el elemento de la lista usando .pop(). 

# En el menú o función eliminar
especie_eliminar = input("Ingrese especie a eliminar: ")
pos = buscar_bicho(lista_bichos, especie_eliminar)

if pos != -1:
    # Eliminamos y podemos recuperar el diccionario eliminado
    eliminado = lista_bichos.pop(pos)
    print(f"Se eliminó el bicho '{eliminado['especie']}' correctamente.")
else:
    print(f"El bicho '{especie_eliminar}' no se encuentra registrado.")
8 Actualización de Estados Iterativa Modificar todos

Recorremos cada diccionario dentro de la lista y actualizamos el valor de la clave correspondiente según las condiciones del enunciado. 

def actualizar_estados(lista):
    for bicho in lista:
        if bicho["peligrosidad"] >= 7.0:
            bicho["peligroso"] = True
        else:
            bicho["peligroso"] = False
    print("Estados actualizados.")
9 Mostrar con Formato y Condición de Estado Formato

Evaluamos el valor booleano interno del estado para imprimir una etiqueta visual ("PELIGROSO" / "NO PELIGROSO") en vez de imprimir True o False. 

def mostrar_bichos(lista):
    actualizar_estados(lista) # Reutilizamos la función
    print("\n=== LISTA DE BICHOS ===")
    
    if len(lista) == 0:
