Python def saludar(nombre): print(f"Hola {nombre}") resultado = saludar("Ana") print(resultado)

¿Qué aparece en la consola? ¿Cuántas líneas?

La función imprime pero no tiene return. Cuando guardas el resultado de una función sin return, Python le asigna None.

2

¿Qué imprime este código? 🔍

Python def doble(x): return x * 2 a = doble(5) b = doble(doble(3)) print(a, b)

¿Qué valores tienen a y b?

✅ Respuesta:

10 12

doble(5) → 10. Para b: primero doble(3) → 6, luego doble(6) → 12. Se puede usar el return de una función como argumento de otra.

3

¿Qué imprime este código? 🔍

Python x = 10 def cambiar(): x = 99 return x resultado = cambiar() print(x) print(resultado)

¿Cuánto vale x después de llamar a cambiar()?

✅ Respuesta:

10 99

La x dentro de la función es local (scope). No modifica la x global. resultado recibe el return (99), pero la x original sigue siendo 10.

¿Qué es una función? 🪥

Imagina que cada vez que quieres lavarte los dientes tuvieras que explicar: «agarra el cepillo, pon pasta, mueve la mano, enjuaga...»

return vs print — La confusión #1

El 80% de los errores de principiantes viene de aquí.

🖨️ print()

Muestra algo en pantalla.
Solo para el humano.
El programa NO puede usarlo después.

VS

📬 return

Entrega un valor al programa.
Comunicación entre funciones.
El programa SÍ puede usar ese valor.

return vs print — En código

Python def sumar_print(a, b): print(a + b) # solo IMPRIME, no entrega nada def sumar_return(a, b): return a + b # ENTREGA el resultado resultado1 = sumar_print(3, 4) # en pantalla: 7 print(resultado1) # pero esto imprime: None !! resultado2 = sumar_return(3, 4) # no aparece nada en pantalla print(resultado2) # esto imprime: 7

⚠️ Sin return, Python asigna None automáticamente.

2

Valores por Defecto

Un parámetro puede tener un valor de «respaldo» si no se especifica.

Python def saludar(nombre, idioma="español"): if idioma == "español": print(f"Hola, {nombre}") elif idioma == "inglés": print(f"Hello, {nombre}") saludar("Juan") # usa "español" por defecto saludar("John", "inglés") # sobreescribe el default

💡 Los parámetros con default van después de los que no lo tienen.

3

Mutabilidad — Crítico para el examen 🧬

✅ Listas y Dicts (mutables)

Se pasan «por referencia».
La función modifica el original.
.append() cambia la lista de afuera.

VS

❌ Números y Strings (inmutables)

Se pasan «por valor».
La función recibe una copia.
El original no cambia.

🎯 Para el examen: al agregar un estudiante, haz .append() a la lista. No necesitas retornarla — el cambio ya quedó.

Mutabilidad — En código

Python # LISTA: el cambio SÍ se mantiene afuera def agregar_fruta(lista_frutas): lista_frutas.append("manzana") # sin return mis_frutas = ["pera", "uva"] agregar_fruta(mis_frutas) print(mis_frutas) # ['pera', 'uva', 'manzana'] ✅ # NÚMERO: el cambio NO se mantiene afuera def intentar_cambiar(numero): numero = numero + 100 x = 5 intentar_cambiar(x) print(x) # sigue siendo 5 ❌

Funciones de Validación 🔍

Responden una pregunta de sí o no. Retornan True o False.

✨ Versión Pythónica

def es_mayor(edad): return edad >= 18
=

📝 Versión Explícita

def es_mayor(edad): if edad >= 18: return True else: return False

Ambas producen exactamente lo mismo. Usa la que entiendas mejor.

5

Búsqueda: Posición o -1 🔎

Uno de los patrones más importantes del examen.

Python def buscar_posicion(lista, valor_buscado): for i in range(len(lista)): if lista[i] == valor_buscado: return i # ¡encontramos! return corta el ciclo return -1 # si el for terminó sin encontrar

📌 -1 nunca es una posición válida → funciona como señal de «no encontrado»

⚡ return termina la función inmediatamente, sin importar dónde esté.

6

Separación de Responsabilidades 🎯

Cada función hace UNA sola cosa y la hace bien.

buscar()
→ retorna posición
→
Buscar alumno
→ muestra datos
buscar()
→ retorna posición
→
Eliminar alumno
→ lo elimina

✅ La misma función de búsqueda se reutiliza para contextos diferentes.

7

Funciones dentro de Funciones 🧱

Una función puede llamar a otra. Es la base de la organización modular.

Python def buscar_posicion(lista, valor): for i in range(len(lista)): if lista[i] == valor: return i return -1 def eliminar(lista, valor): posicion = buscar_posicion(lista, valor) # ¡reutilizamos! if posicion != -1: lista.pop(posicion) print("Eliminado correctamente") else: print("No se encontró")
8

Recorrer y Modificar TODOS 🔄

Aplicar una regla a cada elemento de la lista, sin excepción.

Python # Con listas de números: usar índices def aplicar_descuento(lista_precios): for i in range(len(lista_precios)): lista_precios[i] = lista_precios[i] * 0.9 # Con listas de DICCIONARIOS: directo def marcar_todos_revisados(lista_productos): for producto in lista_productos: producto["revisado"] = True

💡 Con diccionarios, for producto in lista funciona para modificar porque producto es una referencia al diccionario real (Concepto 3).

9

El Dispatcher 📞

Como un operador de central telefónica: recibe una señal y la despacha al lugar correcto.

Python opcion = leer_opcion() if opcion == 1: agregar_estudiante(lista) elif opcion == 2: buscar_estudiante(lista) elif opcion == 3: eliminar_estudiante(lista) elif opcion == 6: print("Adiós") break

✅ Para el examen, if/elif/else es perfectamente válido y suficiente.

10

while True + break — El menú 🔁

Un menú se repite indefinidamente hasta que el usuario decide salir.

Python while True: mostrar_menu() opcion = leer_opcion() if opcion == 6: print("Adiós") break # rompe el ciclo infinito # ... resto de las opciones (dispatcher)

💡 while True + break es el patrón estándar para «repetir hasta que pase algo que decido durante el ciclo».

11

Validar Entradas: Pedir hasta que sea válido 🔒

Versión .isdigit()

def pedir_edad(): while True: e = input("Edad: ") if e.isdigit() and int(e)>0: return int(e) print("Inválida")
ó

Versión try/except

def pedir_edad(): while True: try: e = int(input("Edad: ")) if e > 0: return e except ValueError: pass print("Inválida")

Elige UNA estrategia y sé consistente en todo tu examen.

Validar Texto Vacío o Solo Espacios 📝

🔧 Versión Manual

def tiene_contenido(texto): for caracter in texto: if caracter != " ": return True return False

✨ Versión .strip()

def tiene_contenido(texto): return texto.strip() != ""

.strip() elimina espacios al inicio y al final.

Contar Elementos con Condición 🧮

📝 Con contador

def contar_aprobados(lista): contador = 0 for est in lista: if est["aprobado"]: contador += 1 return contador
=

✨ Con sum()

def contar_aprobados(lista): return sum( 1 for est in lista if est["aprobado"] )

Ambas son válidas. La versión con contador es más fácil de explicar.

Crear un Registro con Valores Fijos 📋

Python def crear_estudiante(nombre, edad, nota): estudiante = { "nombre": nombre, "edad": edad, "nota": nota, "aprobado": False # siempre inicia en False } return estudiante

✅ "aprobado" NO se pide al usuario — el sistema lo asigna por defecto y lo actualiza después con otra función (Concepto 8).

Desafío: Mutabilidad 🧬

Python def agregar(lista, valor): lista.append(valor) def intentar_cambiar(numero): numero = numero + 100 frutas = ["🍎", "🍊"] x = 5 agregar(frutas, "🍇") intentar_cambiar(x) print(frutas) print(x)

¿Qué imprime frutas? ¿Y x?

✅ Respuesta — Concepto 3 (Mutabilidad):

['🍎', '🍊', '🍇'] 5

Las listas son mutables → .append() modifica el original. Los números son inmutables → la reasignación dentro de la función NO afecta a x.

2

Desafío: Búsqueda 🔎

Python def buscar(lista, objetivo): for i in range(len(lista)): if lista[i] == objetivo: return i return -1 notas = [5.5, 7.0, 3.8, 6.2] print(buscar(notas, 7.0)) print(buscar(notas, 4.0))

¿Qué retorna cada buscar()? ¿Por qué?

✅ Respuesta — Concepto 5 (Posición o -1):

1 -1

7.0 está en la posición 1 (índices empiezan en 0). 4.0 no existe en la lista, así que retorna -1 como señal de «no encontrado». El return dentro del for corta la ejecución inmediatamente.

Desafío: Sistema Completo 🏗️

Python def crear(nombre, nota): return {"nombre": nombre, "nota": nota, "aprobado": False} def actualizar(lista): for est in lista: est["aprobado"] = est["nota"] >= 4.0 alumnos = [] alumnos.append(crear("Ana", 5.5)) alumnos.append(crear("Bob", 3.2)) actualizar(alumnos) print(alumnos[0]["aprobado"], alumnos[1]["aprobado"])

¿Cuántos conceptos puedes identificar? ¿Qué imprime?

✅ Respuesta — Conceptos 3, 8, 15:

True False

C15: crear() crea un registro con "aprobado": False. C3: .append() modifica la lista original. C8: actualizar() recorre TODOS y modifica cada diccionario. Ana (5.5 ≥ 4.0) → True. Bob (3.2 < 4.0) → False.
